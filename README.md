# Calculator

A calcultor build in DevOps Module

This calculator will use python 3 and be used from the terminal and is being built to showcase the stages of DevOps and its overall role in software development

## What v1 will be able to do
Take 2 inputs from user
Add
Subtract
Divide
Multiply
Output the result

##How to run
From week 3 using the command: python3 calculator.py
Enter the first number, then operation and then the second number
the program will output the resut in the terminal
